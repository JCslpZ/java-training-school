# Java Training School

A Java-based simulation of a training school developed as part of my
BSc Computer Science degree at the University of Southampton.

## Overview

The program models students, instructors, subjects and courses and
simulates enrolment, teaching allocation and student progress.

## Technologies

- Java
- Object-Oriented Programming
- Collections
- File I/O
- Exception Handling

## Key Concepts

- Inheritance
- Composition
- Encapsulation
- Collections
- File input/output
- Exception handling
