# Java Training School

A Java-based training school simulation developed as part of my BSc Computer Science degree at the University of Southampton.

## Overview

This project simulates the operation of a training school, modelling students, instructors, subjects and courses.

The system supports functionality such as student enrolment, instructor allocation, course management and tracking student progress.

## Technologies

* Java
* Object-Oriented Programming
* Collections
* File I/O
* Exception Handling

## Key Concepts

* Classes and objects
* Encapsulation
* Inheritance
* Composition
* Collections
* File input/output
* Exception handling

## Project Structure

The source code is organised into separate classes representing the main entities and functionality within the training school simulation.

## Running the Project

1. Clone the repository.
2. Open the project in a Java-compatible IDE.
3. Compile the source files.
4. Run the main application.

Developed as part of my Computer Science degree at the University of Southampton to apply Java programming and object-oriented software development concepts.
